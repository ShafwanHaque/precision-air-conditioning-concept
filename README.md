# Precision Air Conditioning & Heating Website Concept

Standalone local outreach preview shaped around the company’s published services and identity.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Project notes

- Prospect site: https://precisionacandheat.com/
- Hero and logo images reference official site/CDN assets when available; the hero graphic for Bill Bradley Services is an original concept illustration because its homepage carousel currently uses a blank placeholder banner.
- Company details, contact information, theme, and service areas are in `src/config/site.config.ts`; confirm details before any launch.
- The contact form is a preview and does not send submissions. Map tiles need an internet connection; map coverage is representative.
